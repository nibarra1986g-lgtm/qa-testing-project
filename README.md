# qa-testing-project
Proyecto de pruebas utilizando Gerkin. Incluye casos de prueba para validar funcionalidades web y escenarios positivos y negativos.
Diseñar y documentar casos de prueba utilizando Gherkin
para validar una plataforma de movilidad integrada con:

- Aplicaciones móviles iOS
- Aplicaciones móviles Android
- Backend / API
- Base de datos
- Back Office
- Sitio Web

## Bloque 1 - Casos de Uso

### Casos incluidos

1. Registro de Usuario
2. Informe de Transacciones desde iOS
3. Integración Backend y Back Office
4. Historial de Transacciones
5. Pruebas de Rendimiento
6. Actualización de Estado desde Android

## Estrategia de pruebas

Se consideran:

- Pruebas funcionales
- Pruebas negativas
- Pruebas de integración
- Pruebas End-to-End
- Pruebas de concurrencia
- Pruebas de rendimiento
- Validación de integridad de datos
- Manejo de errores
- Compatibilidad iOS/Android
